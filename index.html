How it works
Four steps.
One smart decision.
01
💬

Natural language query

An operator or agent asks a question in plain English — no schema required.

02
🔍

Intent classification

GPT-4o-mini classifies the query into one of four intents — routing, forecasting, quality investigation, or fleet status.

03
⚙️

Deterministic scoring

Python logic scores every model across five factors — latency, cost, error rate, status, and quality trend. No LLM involved.

04
✅

Grounded response

The LLM narrates pre-computed evidence only — constrained to system state, never speculation.
